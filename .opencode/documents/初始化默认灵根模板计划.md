# 改造目标
- 依据你的需求，落地灵根对以下行为的实际影响（代码实现）：
  - 闭关：奇遇/宝物概率提升（chance），修为收益倍率（cultivation）。
  - 突破：成功率提升（probability）。
  - 修炼速度：获取修为的倍率（cultivation）。
  - 战斗防御：最终防御的倍率（combat/defense）。
- 倍率控制在 ±1.5（下限 0.5，上限 1.5），英文字段后带中文标注，提供 7 个默认灵根模板。

# 技术实现方案
- RootSystem Hooks 语义（统一数据格式）：
  - `on_cultivation_gain 修炼收益倍率`：`{"on":"on_cultivation_gain","mul":x}`（x∈[0.5,1.5]）
  - `on_seclusion_encounter 闭关奇遇概率加成(%)`：`{"on":"on_seclusion_encounter","bonus_percent":p}`（p为百分比点，加和后裁剪）
  - `on_breakthrough_check 突破成功率加成(%)`：`{"on":"on_breakthrough_check","bonus_percent":p}`
  - `on_player_defense 防御倍率`：`{"on":"on_player_defense","mul":x}`
- 代码改动：
  1. `core/attribute_system.py`：在最终属性计算时应用 `on_player_defense` 的 `mul` 到 `defense`，并保留战斗倍率 `combat_multiplier`。
  2. `core/event_system/effects/retreat_effect.py`：
     - 读取玩家灵根 hooks，应用 `on_cultivation_gain.mul` 到闭关基础收益；
     - 应用 `on_seclusion_encounter.bonus_percent` 到奇遇/宝物概率（并与现有 buff 源叠加，裁剪 0–100%）。
  3. 新增 `BreakthroughCheckEffect`：根据基础成功率与灵根 `on_breakthrough_check.bonus_percent` 计算最终成功率，返回修真语境文案。
  4. 防御场景：在需要的战斗效果中读取 `on_player_defense.mul`，先实现到属性系统，后续若有战斗计算再复用。
- 边界与保护：所有倍率/加成都做裁剪：`mul` ∈ [0.5,1.5]，`bonus_percent` 合并后 ∈ [0,100]。
