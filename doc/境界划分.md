炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙 这十大境界为主干，并补充每个境界的关键细节。

🌱 下境界：凡尘蜕凡，初悟大道
此阶段重在打磨肉身与真元，寿元有限，是修仙路上最脆弱也最关键的奠基期。

1. 炼气期
核心：吸纳天地灵气，淬炼肉身，将体内凡气转化为真气。

小境界划分：通常细分为1至13层（或10层/12层），层数越高，真气越深厚。第13层被称为“炼气大圆满”。

寿元与能力：寿元与凡人无异，或略延长至120-150岁。能力上，可施展火球术、御风术等基础法术，操控低阶符箓，能以“御物术”隔空取物。这是门派里数量最多的基层弟子。

关键突破：将真气压缩成液态真元，并冲破全身玄关，即可尝试筑基。

2. 筑基期
核心：炼气成液，化虚为实，将气态真气压缩为“真元”，彻底脱胎换骨，是真正修仙的起点。

小境界划分：初期、中期、后期、大圆满（或假丹境）。

寿元与能力：寿元暴涨至200-250岁。可辟谷数月不食，御器飞行（真正意义上的飞），神识可外放探查，能使用灵器级的法宝。筑基失败则会修为尽散，大多数人终生止步于此，是门派的中坚力量。

关键突破：将液态真元不断凝炼、压缩，直至结成固态的“金丹”。

3. 金丹期
核心：真元凝结成一颗不朽的金丹，这是修士大道之基，一身精华所在。

小境界划分：初期、中期、后期、大圆满。金丹根据凝练程度和内蕴神通，有九品之分，一品最高，九品最次，直接影响未来潜力。

寿元与能力：寿元可达500-600岁，可称“真人”。能放出丹火炼制高品质丹药与法宝，神识范围大幅扩张，金丹本身也可离体作为强大武器。结丹时会引发小天劫或心魔劫。

关键突破：金丹内孕育出一点灵性，丹破婴生。

🧘 中境界：神通初成，超凡入圣
此阶段神魂可以独立于肉身存在，神通法力产生质变。

4. 元婴期
核心：金丹破碎，化为一尊与本尊相貌相同的婴儿状法体，是为“元婴”。元婴不死，修士不灭。

小境界划分：初期、中期、后期、大圆满。元婴初生时极为脆弱，需在体内温养，后期则可稳固。

寿元与能力：寿元跃升至千年以上（约1000-2000年）。元婴可离体，神游千里，瞬息即至。即便肉身被毁，只要元婴逃脱，便可夺舍重生或寻找天材地宝重塑肉身。掌握瞬移神通，举手投足间引动天地元气。

关键突破：元婴不断壮大，最终与修士元神彻底合一，不分彼此，便是化神。

5. 化神期
核心：元婴与元神合二为一，神识发生质变，能够“化神千千万”。

小境界划分：初期、中期、后期。

寿元与能力：寿元约2000-3000岁。神识可脱离肉身遨游万里，并能神识化形直接发起攻击，也可将自身神识分化，寄附于众多傀儡、分身上，一人即一军。开始能够初步感悟和应用天地法则之力。

关键突破：将强大的神识淬炼至虚无，足以承受界面撕裂之力。

☁️ 上境界：合道虚空，人间半仙
此阶段的修炼已不再是单纯的法力积累，而是对天地法则、空间本源的融合与掌控。

6. 炼虚期
核心：淬炼神魂至虚无，使其能在虚空中穿行而不灭，为脱离凡界做准备。

小境界划分：初期、中期、后期。

寿元与能力：寿元大幅延长，可达5000年以上。能够撕裂空间，进行虚空穿梭，这是炼虚期最显著的标志。可抽取虚空之力化为己用，对空间法则有极深理解。

关键突破：将自身融于天地，打破人与天的隔阂。

7. 合体期
核心：肉身与神魂彻底统一，并开始与一方天地相合，达到“天人合一”的雏形。

小境界划分：初期、中期、后期。

寿元与能力：寿元可逾万年。能够调动一方天地元气为己用，施展“法相天地”，化为百丈巨人。举手投足皆有天地之威相随，甚至可以操控一定范围内的元气，言出法随（小范围）。能开辟、稳固小型秘境空间。

关键突破：修为臻至圆满，冥冥中感应到上界召唤与自身的飞升劫难。

8. 大乘期
核心：凡间修炼的顶峰，自身已成无漏之体，功行圆满，随时准备迎来飞升天劫。

小境界划分：通常不再细分为前中后期，以度过了几次“大天劫”或修成了哪些大神通来衡量。也有一些会分为“普通大乘”与“大乘圆满”。

寿元与能力：理论上与天地同寿，但会面临愈加恐怖的定期天劫。其实力已是人间半仙，拥有部分仙人才有的手段，能轻易碾压任何大乘以下的修士。渡过所有天劫，即可飞升。

关键突破：渡过飞升天劫。

9. 渡劫期
核心：这并不是一个所有人都要经历的独立稳定阶段，而是指大乘圆满后，直面并承受飞升天劫的这个过程。

特点：天劫一般分为多轮，常见的有九天神雷劫、乾天罡风劫、阴火焚身劫、域外心魔劫等。渡过，则肉体与魂魄接受洗礼，转化为仙体仙魂；失败，轻则肉身毁灭，元婴逃脱修成散仙（一种要渡十二次散仙劫的悲催路线），重则灰飞烟灭。

🐉 仙界篇：飞升之后，真仙起点
成功渡过天劫，飞升仙界后，生命层次完全跃升，体内的真元也转化为更高阶的“仙元力”，修炼体系进入全新的维度。

10. 真仙
核心：大道之基已立，是为仙界最底层的仙职，但已算真正超脱于凡俗生灵。

后续仙界境界：不同小说的设定在这里开始百花齐放，但常见脉络为：真仙 → 金仙 → 太乙金仙 → 大罗金仙 → 仙王（混元大罗） → 仙帝/道祖等。
