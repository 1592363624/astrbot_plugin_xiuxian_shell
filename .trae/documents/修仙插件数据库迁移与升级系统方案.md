# 目标

* 为 `astrbot_plugin_re_xiuxian` 提供可靠的“数据库迁移/升级”能力，确保版本更新时自动创建新增表、字段、视图与默认数据（如灵根模板、属性键、Provider 注册等），并支持手动触发与状态查询。

# 设计原则

* 版本化：维护 `db_schema_version`（system\_config）与 `db_migrations`（已应用记录），增量迁移、幂等、可重复安全执行。

* 原子性：每次迁移在事务中执行；遇到错误回滚并保留备份。

* 兼容性：SQLite（WAL 模式、外键启用）；使用 `IF NOT EXISTS` 与存在性检查；视图重建使用 `DROP VIEW IF EXISTS` + `CREATE VIEW`。

* 数据驱动：默认数据（属性键、7个灵根模板）通过 `seed` 步骤按“存在则跳过”策略写入。

# 元数据结构

* `system_config`：键 `db_schema_version`（当前版本号，如 `4`），`db_last_migration_at`（时间戳）。

* `db_migrations`：`id INTEGER PK`，`version INTEGER UNIQUE`，`name TEXT`，`checksum TEXT`，`applied_at TEXT`。

# 目录与文件

* `core/database/migrations/`：按顺序放置 SQL/JSON 迁移包

  * `0001_initial.sql`：初始基础表（已有）

  * `0002_events_views.sql`：事件统计视图等（已有）

  * `0003_roots_and_attributes.sql`：新增 `roots/user_roots/attribute_keys/attribute_providers/user_attribute_overrides/v_user_profile`（当前新增）

  * `0004_seed_defaults.json`：默认数据（属性键、灵根模板）

* `core/database/migrator.py`：迁移引擎（aiosqlite）

  * 加载未应用的迁移 → 执行 SQL → 写入 `db_migrations` 记录 → 更新 `db_schema_version` → 处理 `seed` 数据文件

  * 迁移前创建备份（`re_xiuxian.db.bak_<timestamp>`）

  * WAL/外键开关，统一开启

# 迁移内容（与当前功能匹配）

* v3 → v4（示例）

  * 新增表：`roots`、`user_roots`、`attribute_keys`、`attribute_providers`、`user_attribute_overrides`

  * 新增视图：`v_user_profile`

  * 索引：`idx_user_roots_user`、`idx_user_roots_root`、`idx_attribute_providers_key`

* 种子（seed）：

  * 属性键：`attack/defense/hp/mp/crit/cultivation_speed`（英文字段+中文说明）

  * 7 个灵根模板（金、木、水、火、土、雷、天灵根），倍率统一裁剪到 0.5–1.5，hooks 加成点包含：

    * `on_seclusion_encounter 闭关奇遇概率`（bonus\_percent）

    * `on_breakthrough_check 突破成功率`（bonus\_percent）

    * `on_cultivation_gain 修炼收益倍率`（mul）

    * `on_player_defense 防御倍率`（mul）

# 触发方式

* 插件启动时：`PluginService.initialize()` 调用 `Migrator.upgrade_if_needed()` → 自动执行增量迁移。

* 后台管理 API：

  * `GET /api/db/migrations`：已应用/待应用列表与当前版本

  * `POST /api/db/migrate`：手动触发升级（幂等）

  * `POST /api/db/seed`：仅重放默认数据（不会覆盖已有）

# 审慎策略

* 备份：迁移前复制 `.db` 为 `.bak_timestamp`，失败时提示手动回滚。

* 并发：迁移过程持有应用级锁（单线程执行），避免并发迁移；迁移完成后释放。

* 校验：执行后运行 `PRAGMA integrity_check;` 与关键表存在性验证。

# 验证

* 旧库：启动插件 → 自动升级 → 后台“灵根模板/属性管理”菜单可刷新并显示新增数据。
